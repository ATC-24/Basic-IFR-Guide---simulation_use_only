# Basic IFR Course (ATC24)

An unofficial study course for pilots on ATC24 (PTFS), with 7 lessons and a 20-question quiz after each one.

Based on the **ATC24 Basic IFR Guide** v1.1 by Landguy18 (cheesesteakpotato51):
https://docs.google.com/document/d/1vexmY0W3p9noHEcosHiloqJPjw5qFyPiijC0ssVTRJc/edit?tab=t.xvm5a2u48831

For ATC24 simulation use only, not for real-world aviation. Some content may be out of date, so check the official guide and the ATC24 Discord
